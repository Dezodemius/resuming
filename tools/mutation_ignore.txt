# Мутанты, разобранные вручную и признанные эквивалентными.
#
# Формат: <хеш>  # причина
# Хеш печатает сам tools/mutation_diff.py рядом с каждым выжившим мутантом —
# строку отсюда можно скопировать прямо из его вывода.
#
# Ключ — хеш изменения, а не имя мутанта: имена нумеруются по порядку и
# разъезжаются при любой правке функции. Если код изменится, хеш перестанет
# совпадать и мутант вернётся под гейт — это намеренно, запись протухает в
# безопасную сторону.
#
# Сюда попадает только то, что действительно эквивалентно: мутант меняет код,
# но не может изменить наблюдаемое поведение. «Лень писать тест» — не причина;
# в таком случае тест и надо написать. Автоматически отсеиваемое (изменения
# внутри log.*(), текст сообщений исключений, регистр литералов) вносить не
# надо, это делает tools/mutation_ignore.py.
